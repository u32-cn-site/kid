# 新概念英语英译中训练 - 帮助

## 功能概述
基于新概念英语教材的英文到中文翻译训练工具，支持多册教材切换和进度保存。

## 键盘操作

### 句子导航
- **↑** - 上一句
- **↓** - 下一句
- **滚轮向上** - 上一句
- **滚轮向下** - 下一句

### 课程导航
- **←** - 上一课
- **→** - 下一课
- **Ctrl + ←** - 上一册
- **Ctrl + →** - 下一册

### 显示控制
- **空格键** - 切换单词遮挡显示/隐藏
- **鼠标左键按住** - 去掉单词遮挡
- **鼠标左键松开** - 恢复单词遮挡

## 数据源
- 从 `../../data/index.json` 加载教材列表
- 从 `../../data/nceX/lesson_Y.json` 加载具体课程内容

## 状态保存
- 自动保存当前进度到本地存储
- 包括：教材、课程、句子位置、显示状态
- 下次访问时自动恢复上次进度

## 界面说明
- **顶部**：显示当前教材、课程、标题和进度
- **主区域**：
  - 上方：英文句子（大字体，每个单词被遮挡）
  - 下方：中文句子（蓝色，每个单词被遮挡）

## 遮挡功能
- 中英文同时显示，每个单词独立遮挡
- 遮挡时显示为黑色方块，保留单词宽度
- 空格键切换单词遮挡显示/隐藏
- 鼠标左键按住去掉遮挡，松开恢复遮挡

## 快捷操作技巧
1. **切换单词遮挡**：空格键切换显示/隐藏
2. **临时查看**：鼠标左键按住去掉遮挡，松开恢复
3. **连续练习**：使用方向键或滚轮快速切换句子
4. **跨教材学习**：Ctrl+方向键快速切换教材
5. **进度追踪**：系统自动保存，关闭浏览器后仍保留进度
